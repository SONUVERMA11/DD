ARCHITECTURE

Built to last

Production-grade Android engineering with modern best practices.

Pattern

MVVM + Clean Architecture

ViewModels with StateFlow, Repository pattern, DataStore for preferences, Room for caching.

UI

Jetpack Compose

100% declarative UI with custom Canvas drawings, animated transitions, and Material 3 components.

DI

Hilt

Compile-time dependency injection. Singletons for network clients, DAOs, and preferences.

Network

OkHttp + Jsoup + Retrofit

REST APIs via Retrofit, HTML scraping via Jsoup, with coroutine-based parallel execution.

Storage

Room + DataStore

Room for search cache, download history, and library. DataStore for 50+ user preferences.

CI/CD

GitHub Actions

Automated cloud builds on every push. Debug + Release APKs generated and uploaded as artifacts.
